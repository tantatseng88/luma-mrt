App flow

  1. Pick a source: Luma's Singapore events list (default), your Luma iCal feed, an event link, or a file.
  2. Show the events on a month calendar. Tapping a date lists that day's events, and the user picks one. The next upcoming event is selected to start.
  3. Find the nearest stations from the event's coordinates (or geocode the address with OneMap), then the closest exit.
  4. Ask for a starting station, or with consent use device location to suggest one.
  5. Route on the MRT graph: lines, direction, interchanges, alighting stop, time.
  6. Walking leg from the best exit (OneMap walk routing), plus Google Maps and OneMap links.
  7. Show "leave by" time from the event start, with a reminder option.

Stack and data

  • Next.js or similar with a small server for feed fetching and page parsing (no CORS issues, secrets stay server side).
  • Station and exit coordinates: LTA datasets on data.gov.sg / LTA DataMall. Refresh when lines open.
  • Routing: own graph for MRT legs; OneMap routing API (free account token) or Google Directions transit for walking and door-to-door checks.
  • Train disruptions: LTA DataMall train service alerts, shown above the route.

Preview limits: station list is hand-entered and covers the six MRT lines (no LRT, no Circle Line Stage 6). Timings are estimates (about 2.3 min per stop, 5 min per transfer). Always check the live map links.
